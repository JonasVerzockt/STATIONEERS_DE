# STATIONEERS_DE

## Beschreibung

Dies ist das Repository für meine deutschen Übersetzungen für das Spiel Stationeers.

## Steam Workshop

Die Übersetzung kann über den Steam Workshop bezogen werden:

[Deutsche Übersetzung im Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3032318024)

## Crowdin

Die Übersetzung wird über Crowdin verwaltet und kann dort bearbeitet und verbessert werden:

[Stationeers DE Übersetzungsprojekt auf Crowdin](https://de.crowdin.com/project/stationeers-de)

## Mitwirken

Jeder ist herzlich eingeladen, an der Übersetzung mitzuwirken. Bitte besucht das Crowdin-Projekt, um Fehler zu melden oder neue Übersetzungen vorzuschlagen.
